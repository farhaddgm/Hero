# کنترل تغییر

هر تغییر باید به یکی از این مسیرها نگاشت شود:

1. تغییر کد: commit، تست و Evidence
2. تغییر معماری: ADR و پیامدها
3. تغییر رودمپ: Change Log و دلیل
4. تغییر قاعده: نسخه‌ی جدید و شناسه‌ی جایگزین
5. تغییر مجوز: ردیف append-only با وضعیت جدید

ویرایش خاموش نسخه‌ی مصوب مجاز نیست. سند جدید می‌تواند نسخه‌ی قبلی را جایگزین کند، اما نسخه‌ی قبلی حذف نمی‌شود.

گسترش دامنه باید در Spec گام ثبت شود. Agent حق ندارد صرفاً برای راحتی، قابلیت خارج از معیار پذیرش اضافه کند.
