# تعریف Done

هر گام برای تکمیل باید همه‌ی کنترل‌های زیر را عبور کند:

- معیار پذیرش سند مصوب برآورده شده باشد.
- تست مناسب و Build موفق باشد.
- Hero Doctor و کنترل Clean-room موفق باشند.
- مستندات و راهنمای کاربر به‌روز باشند.
- Run ID، Auth ID، نتیجه تست و Artifact ثبت شده باشند.
- یافته‌ی امنیتی مسدودکننده وجود نداشته باشد.
- مسیر Rollback یا Recovery روشن باشد.
- تغییرات در Google Sheet مدیریت ثبت شده باشند.

اگر کنترلی قابل اجرا نیست، گام فقط با هشدار و بدهی صریح می‌تواند «Prototype» باشد؛ وضعیت «تکمیل» نمی‌گیرد.
