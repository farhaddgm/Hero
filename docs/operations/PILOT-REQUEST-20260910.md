# درخواست پیشنهادی پایلوت Hero — HERO-PILOT-001

وضعیت: `awaiting-owner-approval`

برای حذف ابهام، یک پایلوت کوچک، کم‌ریسک و قابل‌اندازه‌گیری تعریف شده است: ساخت یک وب‌اپ تک‌صفحه‌ای فارسی و RTL برای ثبت و پیگیری کارها. داده فقط در مرورگر نگه‌داری می‌شود و ورود کاربر، API بیرونی، پیام، پرداخت و Production خارج از دامنه‌اند.

قرارداد ماشینی کامل در [HERO-PILOT-001-v1.0.json](../../config/pilot/HERO-PILOT-001-v1.0.json) است. موفقیت نیازمند پاس‌شدن همهٔ معیارهای اجباری، `pnpm check`، نبود finding بحرانی/بالا، امتیاز Evaluator حداقل ۸۵، تأیید Verifier و Code Reviewer و rollback آزموده‌شده است.

## تصمیم پیشنهادی Provider

- فقط Provider برابر OpenAI برای پایلوت اول؛
- نقش‌های خواندنی از خانوادهٔ ChatGPT و Executor از خانوادهٔ Codex؛
- Model ID دقیق فقط پس از بررسی دسترسی حساب مالک ثبت می‌شود؛
- سقف پیشنهادی کل پایلوت ۵ دلار است؛ در Hero هر cost unit برابر `0.0001 USD` تعریف می‌شود، پس سقف پیشنهادی `50000` واحد است؛
- یک مجوز زمان‌دار، محدود به `HERO-021/v1.0` و role/modelهای صریح لازم است.

این سند مجوز هزینه یا اجرا نیست. برای تصویب، مالک باید جملهٔ دقیق بخش «کار مالک» در [EXTERNAL-SPEND-AUTHORIZATION.md](./EXTERNAL-SPEND-AUTHORIZATION.md) را پس از انتخاب Model ID و سقف هزینه تأیید کند.
