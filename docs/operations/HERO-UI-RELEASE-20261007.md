پیش از هر مرحله، Step ID و نسخه با Snapshot فعال تطبیق داده می‌شوند و Global Stop باید خاموش باشد. Snapshot پیشین بازطراحی تغییر نمی‌کند. فقط منابع Hero هدف‌اند. پیکربندی runtime و credentialها حفظ می‌شوند؛ فایل خارج از Git boundary خوانده یا نوشته نمی‌شود. Migrationهای جدید باید افزودنی و قابل سازگاری با نسخهٔ قبلی باشند. کانتینر و image قبلی برای rollback حفظ می‌شوند. هیچ عملیات پاک‌سازی دادهٔ واقعی در این انتشار انجام نمی‌شود.

نتایج واقعی پس از اجرای بررسی‌ها در Evidence انتشار ثبت می‌شوند. تست مرورگر محلی با fixture ساختگی است؛ وضعیت UI پشت احراز هویت عمومی فقط با دسترسی مجاز قابل تأیید است.
