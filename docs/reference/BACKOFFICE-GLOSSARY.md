- **Desired State:** وضعیت مصوبِ هدف؛ تغییر آن نسخه‌دار است.
- **Observed State:** وضعیت گزارش‌شده؛ تفاوت آن با desired فقط Proposal می‌سازد.
- **Node Agent:** عامل اجرایی دارای identity که intent جدید نمی‌سازد.
- **Secret Ref:** شناسهٔ غیرحساس محل Secret؛ مقدار Secret نیست.
- **Break-glass:** درخواست زمان‌دار و حسابرسی‌شده برای بررسی استثنایی؛ به‌خودی‌خود data access نیست.
- **Artifact:** خروجی دارای digest، provenance، attestation و SBOM reference.
- **Delivery Bundle:** manifest قابل‌انتقالِ بدون Secret برای تحویل.
- **Health:** وضعیت توضیح‌پذیر با driver، confidence و freshness.
- **Readiness Review:** جمع‌بندی gap/risk/limitation/rollback پیش از پذیرش Owner.
- **Pilot Proposal:** پیشنهاد محدود بعد از acceptance؛ اجرای Pilot نیست.
