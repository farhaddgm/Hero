# Hero — Release Policy

- Document ID: `HERO-PRODUCT-HERO-RELEASE`
- Version: `1.0.0`
- Status: `active`
- Scope: `product`
- Owner: `hero-release`

## سیاست

هر Release Hero باید از تغییرات canonical در Git، کنترل‌های CI، تست، Evidence و review مالک عبور کند. Product Studio و Notion projection قابل rebuild هستند و منبع حقیقت Release محسوب نمی‌شوند.

## Notion

فعال‌سازی connector، ارسال محتوا، webhook، Secret و promotion عملیاتی هرکدام مجوز جداگانه دارند. ویرایش Notion فقط Change Proposal ایجاد می‌کند و بدون merge شدن Pull Request، وضعیت رسمی Hero تغییر نمی‌کند.
