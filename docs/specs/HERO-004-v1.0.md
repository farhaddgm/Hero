# HERO-004 v1.0 — پایه مستقل و قابل‌انتقال

وضعیت: مصوب برای توسعه و تست در 2026-08-14.

## هدف

ساخت یک monorepo مستقل که بدون استفاده از کد، فایل، دیتابیس، سرویس یا پیکربندی پروژه‌های دیگر قابل توسعه و انتقال باشد.

## دامنه مجاز

- ساخت ساختار مخزن، سرویس سلامت حداقلی، تست، Doctor، Docker، Compose و CI
- خواندن و نوشتن فقط در ریشه Git همین پروژه
- استفاده از Node.js و Git نصب‌شده به‌عنوان ابزار عمومی سیستم

## خارج از دامنه

- خواندن یا تغییر پروژه‌های همسایه
- اتصال واقعی Codex، Claude یا Cursor
- استقرار Production، خرید سرویس، تغییر Secret یا اقدام برگشت‌ناپذیر

## معیار پذیرش

1. Build و تست‌ها موفق باشند.
2. Hero Doctor موفق باشد و symlink، submodule، وابستگی محلی، import بیرونی و مسیر میزبان را رد کند.
3. تنظیمات از environment خوانده شوند و Secret وارد Git نشود.
4. Linux container محیط مرجع انتقال باشد.
5. راهنمای انتقال به سرور دیگر وجود داشته باشد.
