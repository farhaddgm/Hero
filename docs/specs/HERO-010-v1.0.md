# HERO-010 v1.0 — داشبورد کنترل اولیه

وضعیت: مصوب برای توسعه و تست در 2026-08-14.

## هدف

کاربر غیر فنی باید بتواند یک درخواست را با زبان ساده ثبت کند، برنامهٔ پیشنهادی آن را ببیند، آن را تأیید یا رد کند، اجرای Fake Agent را آغاز کند و نتیجهٔ قابل فهم آن را دریافت کند.

## قابلیت‌های این نسخه

1. رابط فارسی و راست‌به‌چپ در مسیر اصلی کنترل‌پلین ارائه می‌شود.
2. ثبت درخواست جدید، انتخاب چهار سناریوی Fake Agent و نمایش برنامهٔ چهاربخشی انجام می‌شود.
3. تأیید، رد، توقف درخواستِ اجرا نشده، اختیار کامل برای آماده‌سازی درخواست‌های تازه و توقف اضطراری در دسترس است.
4. اجرای Fake Agent فقط بعد از وضعیت «آماده اجرا» ممکن است و نتیجه شامل تلاش‌ها، وضعیت Runnerهای پاک‌سازی‌شده و تعداد رویدادهاست.

## مرز اختیار و ایمنی

حالت اختیار کامل در این گام فقط درخواست تازه را «آماده اجرا» می‌کند؛ Provider واقعی، هزینه، production، secret، پیام بیرونی و هر عملیات حساس همچنان خارج از محدوده است. توقف اضطراری قبل از تأیید یا dispatch جدید، اجرا را fail-closed متوقف می‌کند. اجرای Fake Agent همگام و بدون شبکه است؛ بنابراین توقفِ Run زنده در این نسخه موضوعی ندارد و کنترل checkpoint زنده در گام Runner واقعی اضافه می‌شود.

## API اولیه

- `GET /` صفحهٔ کنترل فارسی را می‌دهد.
- `GET /api/dashboard` وضعیت کنترل‌ها و درخواست‌ها را می‌دهد.
- `POST /api/requests` درخواست و برنامه را می‌سازد.
- `POST /api/requests/:id/approve|reject|stop|run` اقدام کاربر را اعمال می‌کند.
- `POST /api/authority` و `POST /api/global-stop` کنترل اختیار و توقف را اعمال می‌کنند.

داده‌ها در حافظه‌اند و صرفاً برای رابط اولیه و Fake Agent استفاده می‌شوند؛ persistence و اتصال Provider واقعی در این گام وجود ندارد.

## معیار پذیرش

1. کاربر بتواند بدون اصطلاح فنی یک درخواست ثبت و برنامهٔ آن را مشاهده کند.
2. تأیید لازم، رد، توقف، اختیار کامل و توقف اضطراری از طریق API و رابط قابل آزمایش باشند.
3. اجرای Fake Agent فقط از مسیر مجاز شروع و بدون Provider یا هزینه، چهار سناریوی موجود را گزارش کند.
4. ورودی شبیه secret رد شود و پاسخ Dashboard هرگز secret یا اعتبارنامه برنگرداند.
