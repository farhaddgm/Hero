# HERO-001 v1.0 — منشور پروژه و حاکمیت

## خروجی

منشور باید هدف Hero، دامنه، نقش سه ابزار، صاحب تصمیم، مدل اختیار، گیت عملیات حساس، روش تغییر قواعد و Definition of Done را برای انسان و ماشین مشخص کند.

## اقلام تحویل

- منشور انسان‌خوان
- قرارداد ماشینی governance
- Snapshot محلی اختیار کامل جاری
- سیاست اختیار و توقف
- کنترل تغییر
- Definition of Done
- اعتبارسنج خودکار و تست

## معیار پذیرش

1. هدف و دامنه برای مالک غیرتوسعه‌دهنده قابل فهم باشد.
2. تصمیم‌های محصول، اجرا و کیفیت صاحب روشن داشته باشند.
3. عملیات حساس از اختیار توسعه جدا باشند.
4. قرارداد JSON معتبر و با مستندات منطبق باشد.
5. تست Governance و مجموعه pnpm check موفق باشند.
