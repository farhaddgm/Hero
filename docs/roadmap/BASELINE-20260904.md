## قاعدهٔ تغییر

این baseline با شواهد read-only و خروجی واقعی ابزارها به‌روزرسانی می‌شود. آخرین verification در کانتینر Linux انجام شده و Doctor فقط نبود Docker تو‌در‌تو را هشدار داده است. Test مستقل و دامنهٔ Test اکنون smoke شده‌اند، اما rollback/recovery واقعی و Pilot هنوز اثبات نشده‌اند. commit، deploy، secret change، production action و تغییر اپلیکیشن دیگر در این workspace انجام نشده است.
